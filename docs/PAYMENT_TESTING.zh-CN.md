# 支付测试中心

简体中文 · [English](PAYMENT_TESTING.md)

受保护的 `/admin/test-center` 支付测试中心直接调用商户真实使用的 GMPay、EPay
协议处理器、订单服务、支付状态机、Webhook Outbox 和回调验签逻辑，不维护另一套仅
开发环境可用的下单路径。

## 权限与环境

商户成员需要 `merchant` 读取权限才能查看资源与运行记录，创建权限用于预检和发起，
更新权限用于推进模拟场景、请求网络检查、重试回调或取消运行。当前商户与环境始终由
服务端会话确定。

沙盒与生产资源严格隔离：

- 沙盒只允许内置模拟器和已明确配置的测试网。
- 生产环境只允许主网收款方式，绝不显示模拟器控制。
- 切换商户或环境后，会重新加载该范围内的 API Key、收款方式和历史记录。

每个新商户会自动获得一个启用的沙盒测试 API Key 和模拟器收款方式。测试中心只在
服务端解密并签名，一次性 API Secret 不会出现在快照或页面响应中。

## 模拟器闭环

1. 打开 `/admin/test-center` 并选择沙盒环境。
2. 选择 GMPay 或 EPay、模拟器、测试场景、API Key 和模拟器收款方式。
3. 先执行“检查就绪状态”，再发起测试。
4. 按页面提示推进每一步。模拟交易必须经过正常支付入账服务，不能直接改写订单状态。
5. 打开“查看证据”，检查已脱敏的请求、响应、付款、Webhook、回调接收、审计记录和最终结果。

内置回调接收器是默认选项，可以在当前实例内完成闭环。自定义回调必须是公网 HTTPS
地址；投递前会重新解析域名，私网、本机、保留地址、带账号密码地址和 DNS 重绑定地址
都会被拒绝。

内置场景覆盖精确支付、部分支付后补足、超额支付、逾期支付、失败交易、重复投递、确认数
递进、区块重组后恢复，以及回调失败后重试。

## 测试网闭环

首个版本支持以下沙盒原生资产：

| 网络 | 原生资产 | 运营方要求 |
| --- | --- | --- |
| TRON Nile | TRX | 健康的 Nile RPC 和商户自己的公开收款地址 |
| Ethereum Sepolia | ETH | 运营方配置健康端点和商户自己的公开收款地址 |
| Base Sepolia | ETH | 健康的 RPC 和商户自己的公开收款地址 |
| BSC Testnet | BNB | 健康的 RPC 和商户自己的公开收款地址 |
| Polygon Amoy | POL | 健康的 RPC 和商户自己的公开收款地址 |

Ethereum Sepolia 默认不提供公共端点，启用收款方式前必须配置 Provider 或自有节点。
测试资产应从该网络当前的官方 Faucet 获取，系统中只配置公开收款地址，绝不填写私钥、
助记词或提现凭证。TON、Aptos 和 Solana 在此版本仅支持模拟器。

从引导页发起测试网订单后，按收银台地址转入精确资产金额，再执行“检查付款”。链上观察
会经过正常的只读适配器和确认策略。

## API 控制台与历史记录

`/admin/test-center/console` 支持 GMPay/EPay 协议切换，并显示端点、结构化输入、已脱敏
签名请求、响应、Request ID、状态和耗时。附加原始参数不能覆盖所选 PID、金额、资产、
网络、回调或签名字段。

`/admin/test-center/runs` 提供按当前商户与环境隔离的游标分页历史。运行详情按时间顺序
组合测试运行、订单、付款、Webhook、回调接收和审计证据。持久化快照会递归脱敏并限制
在 64 KiB 以内。

## 生产确认

生产环境涉及真实资金。发起生产测试时，系统先签发短时、一次性的确认凭证，确认框会列出
金额、币种、资产、网络和回调地址。关闭确认框不会创建订单；确认后凭证立即消耗，并通过
正常生产流程创建订单。测试中心不会代替商户发送资金。除非运营方另行明确授权具体金额和
目标地址，生产验收必须停在确认预览。

## 保留与运维

运维设置 `retention.payment_test_evidence_days` 接受 7 至 365 天，默认 90 天。定时清理
先删除回调接收记录，再删除已结束的测试运行；不会删除关联订单、付款、Webhook 事件、
投递、尝试或审计记录。

隐私安全指标覆盖预检、协议请求、订单创建、支付检测、确认和回调投递。指标标签只允许协议、
环境、模式、场景、结果和结构化错误码。

## 故障排查

- **没有兼容的收款方式：** 启用与模拟器、测试网或生产模式网络类别一致的收款方式，并绑定资产。
- **凭证不可用：** 在当前环境选择已启用、未过期且包含 `orders:create` 范围的 Key。
- **收款方式未就绪：** 检查公共端点、返回的 Chain ID、健康状态、地址和资产绑定。
- **回调地址不安全：** 使用公网 HTTPS，移除账号密码，避免跳转到私网或解析出私网/保留地址。
- **运行一直未结束：** 检查证据时间线；真实网络可请求付款检查；只有失败或停止的回调投递才能人工重试。
